
# 希伯来文“求生攻略”

很多人把希伯来文调侃为“学不来文”，希伯来文作为世界上最难的语言之一的确很有难度，不过正是因为困难才有价值，不是吗？让我们一起开启希伯来文的学习之旅吧！


1、一定要多阅读，并且要读出声！
2、单词要背，圣经金句要背。
3、《练习》要做，尤其是翻译。
4、学习语言，重在坚持。
5、最后，一起享受学习的乐趣吧！

# Begadkephat字母

*   希伯来文有6个子音具有两种发音，
*   这6个字母被称为begadkephat子音。
*   这个名称不过是一个记忆工具，
*   以便记住这6个子音（בגדכפת）；
* （Taw Pe Kaf Dalet Gimel Bet）


# 弱Daghesh (Daghesh Lene)

*   弱daghesh表示“塞音”，发音时气流塞住，如b和p；
*   无弱daghesh表示“擦音”，发音时气流在嘴唇间产生摩擦，如v和f；
*   弱daghesh只会出现在begadkephat字母中；

# 喉音字母

*   希伯来文有4个喉音字母，喉音的意思字母的发音在喉咙的后面。这4个喉音字母为：א、ע、ח、ה
*   有时候ר也有喉音的表现；

# 数字值

*   希伯来文无阿拉伯数字，因此，希伯来文字母表的每一个字母都代表一个数字值。א到ט代表1-9；י到צ代表10-90；ק到ת代表100、200、300、400；有关希伯来文的数字系统会在第11单元详细讲解。
